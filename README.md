# Ping Pong

Este proyecto incluye un peque\u00f1o juego de ping pong que se ejecuta en el navegador.

## Uso

1. Ejecuta el servidor de Python:

```bash
python3 server.py
```

2. Abre un navegador y visita `http://localhost:8000` para jugar.

Los controles son:
- Jugador izquierdo: `W` y `S`
- Jugador derecho: flechas arriba y abajo
